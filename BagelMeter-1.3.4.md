# Bagel Meter 1.3.4

- My devices: the left side now shows only what's actually in use on this Mac (open now or used this week).
- New "Not in use" list under it: accounts nobody has used on any of your computers this week, with how much each has left, so you know which one to pick up.
- Account icons are now automatic: each account shows the icon of the computer it's in use on (💻 this Mac, 🪟 your PC…), and no icon when it isn't in use anywhere. Right-click a computer on My devices to change its icon.
- Windows: the helper also reports Claude when the PC only uses the Claude desktop app, and reads whichever account Claude Code switched to most recently.
