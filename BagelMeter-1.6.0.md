# Bagel Meter 1.6.0

- Pace: each account now says where its week is headed, like "Runs out ~Wed 11 PM" or "~40% will go unused", based on how fast it's been used since the last reset.
- New Jobs tab: pick a GitHub repo, and its open issues labeled "bagel" become jobs. Click Run to have the account with the most spare room work on one right on this Mac (Claude Code or Codex), then a pull request opens. Nothing ever goes to the main branch. Stop and Log are there while it runs. Needs the GitHub CLI signed in (gh auth login).
